# Mon Cockpit

Version prête pour GitHub Pages.

## Publication

1. Importer tous les fichiers de ce dossier à la racine du dépôt GitHub.
2. Dans **Settings > Pages**, choisir **Deploy from a branch**.
3. Sélectionner la branche **main** et le dossier **/(root)**, puis enregistrer.
4. Le site sera disponible à l'adresse : `https://vmarjorie.github.io/Mon-cockpit/`

Pour l'installer sur iPhone : ouvrir le site dans Safari, toucher **Partager**, puis **Ajouter à l'écran d'accueil**.
